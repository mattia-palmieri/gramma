# 2026-10-16 — MVP build

## What we decided (and why)
- **Separate app + thin Handy reader** (poll Handy's `history.db` in read-only mode). Why: no Rust toolchain on this Mac, no fork. Handy writes each row before it pastes, and it has no external hook or IPC.
- **Bun + TS, zero npm deps** (bun:sqlite + Bun.serve). Local page on 127.0.0.1:4317 + osascript notification.
- **Model `qwen3:4b` via Ollama** (Apache 2.0, fits on an 8 GB M1). Fallback `qwen3:1.7b`. Gemma 3 was rejected (license terms). Gemma 4 / Qwen3.5 were rejected (too big / `format` bug when thinking is off).
- **Precision first:** the prompt says "no issues is normal". `validate()` drops doubtful issues. Fluency/repetition tips need high confidence.
- Patterns: a fixed category enum (not free text), so counts can be grouped.
- Privacy: store only transcripts that got feedback. Never copy audio.
