How it works

You already talk all day. Now it counts as practice.

1

Dictate

Use Handy like always. Emails, prompts, messages.

2

Gramma reads

A local model checks what you said. Your pasted text is never touched.

3

One useful fix

A small note pops up, then goes away. Said it right? She stays quiet.

Her rules

Strict about mistakes. Relaxed about you.

100% local

No cloud, no account, no audio kept. Runs on an 8 GB Mac.

No false alarms

Casual speech is fine. She only flags real errors. A wrong fix is worse than none.

Zero effort

No lessons, no streaks, no app to open. You learn while you work.

Install

Three lines. Then just talk.

$ brew install bun ollama
$ ollama pull qwen3:4b # 2.5 GB, Apache 2.0
$ bun src/server.ts
